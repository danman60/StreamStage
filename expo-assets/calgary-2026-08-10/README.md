## Baggage — READ BEFORE PACKING

The e-ticket says, on **both** legs:

```
Class: Economy
Luggage:
Not included
```

The payment overview confirms nothing bag-related was bought. The only other line item is
`ServicePackage Basic - included`, which is **BudgetAir's own booking-service tier, NOT the WestJet
fare brand.** Do not read it as a fare class.

**UNRESOLVED: the WestJet fare brand is not printed anywhere in either document.** That brand is
what decides whether the ticket allows a full carry-on plus a personal item, or a personal item
only. Nothing in this folder answers it, and it should not be guessed.

Resolve it in one of two places:
- WestJet Manage Trips, code `LYPROK` plus surname
- BudgetAir My Account, booking `BCA-20856065` plus the booking email

**Why it matters more than usual this trip:** this is an exhibiting trip, not an attending one.
Booth prize ($100+, winner's name to the organiser by 4:00 pm Wed Aug 12), exhibitor packet,
conference shirt and demo hardware all have to travel. With no checked bag on either leg, that is
cabin allowance only. Adding a bag in advance is cheaper than adding one at the airport.
